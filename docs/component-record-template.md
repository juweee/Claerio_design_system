# Component record template

Use this template for each component's record. Experiment 1.3.

## Generated from code

- **Name and import path**
- **Props:** every prop, with types, allowed values and defaults, including standard HTML props the component passes through
- **Variants and states:** each one written out, not referenced
- **Stories:** story IDs and preview links
- **Tokens:** the tokens the component uses

## Written by a person

- **Purpose:** one sentence
- **When to use, when not to:** including the alternative to use instead
- **Anatomy:** the named parts
- **Behavior:** how it responds over time, such as when validation runs
- **Accessibility:** what the component handles, what the person using it must provide, and a short test checklist
- **Content guidance:** label length, case, wording for helper and error text
- **Related components and patterns**
- **Links:** decisions.md entries now, Figma later
- **Status:** stable, new, first pass or deprecated
